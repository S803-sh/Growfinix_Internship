# Real Estate Web Scraper

## Description

A Python web scraping project that extracts publicly available real estate property information and stores the cleaned data in a CSV file.

## Tech Stack

- Python
- Requests
- BeautifulSoup4
- CSV
- Regular Expressions

## Features

- Sends an HTTP request to a public listing page
- Parses HTML using BeautifulSoup4
- Extracts property titles
- Extracts property prices
- Extracts property locations
- Cleans extracted text
- Exports the results to CSV

## Output

The extracted data is saved in:

properties.csv
