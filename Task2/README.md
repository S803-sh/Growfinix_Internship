# Tour Enquiry CLI Tool

A Python command-line tool that extracts useful information from messy tour enquiry text files using Regular Expressions.

## Features

- Extracts customer names
- Extracts email addresses
- Extracts travel destinations
- Cleans extracted data
- Processes multiple enquiries
- Displays a formatted summary directly in the terminal
- Handles missing files and invalid input
- Uses Python `argparse` for command-line arguments
- Uses Python `re` for Regular Expressions

## Tech Stack

- Python
- argparse
- re (Regular Expressions)
