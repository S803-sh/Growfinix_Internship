# IPL Historical Data Analysis

## Description

This project analyzes historical Indian Premier League (IPL) match data using Python, Pandas, and Matplotlib.

The analysis calculates team win rates and specifically examines the historical performance of Kolkata Knight Riders (KKR), including their toss decisions.

## Tech Stack

- Python
- Pandas
- Matplotlib

## Features

- Reads historical IPL match data from CSV
- Calculates total matches played by each team
- Calculates team win counts
- Calculates team win rates
- Filters Kolkata Knight Riders matches
- Calculates KKR win rate
- Analyzes KKR toss decisions
- Exports KKR match data to CSV
- Creates visualizations
